# Duke Nukem 3D shareware bundle

This directory contains Episode One of Duke Nukem 3D shareware 1.3D packaged for js-dos.

- Original installed shareware files: `dn3d-box.zip`, downloaded from [DOS Games Archive](https://www.dosgamesarchive.com/file/duke-nukem-3d/dn3d-box).
- Emulator interface: [js-dos](https://js-dos.com/overview.html).
- The original game files inside the bundle are unchanged. The only addition is `.jsdos/dosbox.conf`, which mounts the archive and calls the included `DN3DWEB.BAT` launcher.
- The complete original `DUKE3D/LICENSE.TXT` is preserved inside the bundle. It permits free websites to distribute the shareware episode when all original files remain included without modification.
