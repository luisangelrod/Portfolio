Equations, sources & what this view can tell you

u″ = 1.5u² − u; u = rₛ / r

Each pixel integrates a Schwarzschild null geodesic with fourth-order Runge–Kutta steps of 0.024 radians, up to 720 steps. A static observer’s local viewing direction determines the impact parameter. A ray hitting the horizon is absorbed; an exhausted step budget is shown in rust, never classified as capture.

The disk is a thin, opaque illustrative emitter between 3 and 11 rₛ. Its power-law temperature profile is chosen, not measured. Planck spectra determine its color through approximate CIE color matching; brightness, fine bands and the procedural stars are illustrative. Optional gravitational redshift assumes static emitters. Disk motion, Doppler beaming, Kerr spin and plasma dynamics are not modeled here. Linear color is tone-mapped once with AgX; subtle bloom is a display effect.

The selected path is a CPU reference in projected Schwarzschild coordinates, not a local measurement of light speed. A prettier image does not establish numerical accuracy. GPU checks verify selected rays, not every pixel.
