# Memory archive asset notes

These marks appear only inside Luis Rodriguez Rivera's personal, non-commercial memory archive as referential artifacts of the era. Their owners do not sponsor or endorse this portfolio.

- `playstation-1994.svg` — original PlayStation mark, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Playstation_logo_colour.svg). PlayStation is a trademark of Sony Interactive Entertainment.
- `nintendo-1983.svg` — Nintendo's red racetrack mark used through the 1980s and 1990s, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Nintendo_red_logo.svg). Nintendo and Game Boy are trademarks of Nintendo.
- `game-boy-logo.svg` — Game Boy wordmark, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Nintendo_Game_Boy_Logo.svg).
- `coca-cola-logo.svg` — Coca-Cola script mark, sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Coca-Cola_logo.svg). Coca-Cola is a trademark of The Coca-Cola Company.

The video-store memory uses original text-only spine treatments rather than film poster artwork.
